### 🤖 AI 개발 — LLM · RAG · 온톨로지를 실무에 적용
* **사내 규정 RAG 챗봇** — 그룹웨어 게시판의 공지·규정·첨부파일을 자동 수집(Playwright)하고, 로컬 임베딩(Ollama bge-m3)·벡터 DB(ChromaDB)로 색인해 사내 규정을 정확히 답하는 FastAPI 기반 챗봇
* **Text-to-SQL 회의 보고서 PoC** — 로컬 LLM(Ollama)이 자연어 질문을 SQL로 바꿔 실데이터를 조회하고 주간 보고서 초안까지 생성. 지표·차원·업무 규칙을 정의한 **시맨틱 레이어**와 골든셋 기반 평가 스크립트로 모델별 정확도를 측정
* **온톨로지 질의 챗봇** — 지점·회원·출석·결제 데이터를 RDF/OWL 온톨로지로 모델링하고 Triple Store(Apache Jena Fuseki)와 LLM을 연동한 대화형 분석
* **주간 업무 보고서 자동 생성기** — 워크스페이스의 Git 커밋과 GitHub PR 내역을 수집해 LLM이 비즈니스 관점으로 요약하고 Slack으로 공유하는 웹 대시보드
